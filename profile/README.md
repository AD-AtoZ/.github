## 👣 발맞춤 — 늦을지, 손목이 먼저 알려 줍니다

> 지도 앱의 예상 시간은 **내 걸음**이 아닙니다.
> 그래서 급할수록 화면을 들여다보며 걷게 되고, 그러다 부딪힐 뻔합니다.

**발맞춤**은 갤럭시 워치 앱입니다. 처음 한 번 **내 걸음 속도**를 재 두면,
걷는 동안 "남은 거리 ÷ 남은 시간"을 내 속도와 비교해서
**상태가 바뀔 때만 손목을 짧게 진동**합니다. 화면을 볼 필요가 없습니다.

| 상태 | 뜻 | 진동 |
|---|---|---|
| 🟢 여유 있음 | 보통 걸음으로 충분 | 없음 |
| 🟡 서두르면 맞춤 | 빠른 걸음이면 도착 | 짧게 1번 |
| 🟠 뛰어야 맞춤 | 뛰어야 도착 | 짧게 1번 |
| 🔴 뛰어도 어려움 | 뛰어도 늦음 | 짧게 1번 |

### 이렇게 씁니다

1. 워치에서 **내 속도 재기**: 보통 걸음 · 빠른 걸음 · 뛰기
2. 휴대폰에서 **목적지와 도착 시각**을 정해 워치로 보내기
3. 걷기 시작 → 상태가 바뀌면 손목 진동

### 기술

`Kotlin` · `Wear OS (Compose for Wear OS)` · `Fused Location Provider` · `TMAP 보행자 경로 API` · `Wearable Data Layer`

| 모듈 | 하는 일 |
|---|---|
| `core` | 도착 판단 로직 (순수 Kotlin, 단위 테스트) |
| `wear` | 워치 앱: 화면, 위치 추적, 진동, 기록 |
| `mobile` | 휴대폰 앱: 목적지 검색, 워치로 전송 |
